# Pokate Labs

Pokate Labs builds infrastructure for AI agents that work with real computers.

**Mission:** make agent work on real computers useful, understandable, and safe to supervise, with bounded access, human control, recoverable changes, and clear evidence of what happened.

This repository contains the public overview of Pokate Labs: our mission and goals, product architecture, current portfolio maturity, roadmap direction, and working principles. Product names describe the portfolio; they do not imply that every product is available or released.
